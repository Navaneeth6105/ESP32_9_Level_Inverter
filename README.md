# ESP32_9_Level_Inverter
ESP32 project file which i wrote for my final year 9 level inverter project
This inverter logic runs at 50kHz where the cpu utilization is only about 20 % from my testing..so there is still some cpu power left for to run advanced PID loops with some additional sensor input for closed feedback system. Currently it is in Openloop,  but the modulation index can be dynamically adjusted so it can be made into a closed loop system . I tried my maximum to optimize the code to work at this speed with much lesser cpu utilisation so that later this code can be modified to make it closed loop without the reduction in current performance.
